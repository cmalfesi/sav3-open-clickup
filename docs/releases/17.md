# Release 17 · 0.10.3

Agrega **Opciones de vista → Eliminar vista** para la pestaña activa de una
lista. La confirmación conserva las tareas y, para una pestaña de dashboard,
conserva el panel en el listado de Dashboards. Protege la última vista de
tareas y activa otra vista disponible después de eliminar.

Los permisos de escritura de lista y, cuando corresponde, del dashboard
se verifican en el servidor. La eliminación registra auditoría y las
preferencias personales de la pestaña se limpian por clave foránea.
