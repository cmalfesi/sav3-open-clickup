# Release 9

Configurable dashboards start empty and can be opened from the hub or created as a list view. Cards include KPIs, bar/pie/line charts, task tables and activity, with source selection, dashboard/card filter intersection, aggregation, drill-down, drag/resize, keyboard ordering and sizing, persistence and refresh controls.

Definitions use revision compare-and-swap, attributed history and explicit sharing. Sharing a panel does not share tasks. Legacy summaries remain editable. Archiving is reversible. No replica of the supplied opportunities dashboard or predefined business KPIs is created.

Validation: 93 passing unit/D1 tests, TypeScript and production build. Layout configuration, metric behavior, hidden tasks, sharing, conflicts and legacy conversion are covered by these tests. Authenticated desktop/mobile browser interaction remains to be checked in an available user session; the connected browser was unavailable during implementation.
