# Release 16 · 0.10.2

Activa enlaces escritos, pegados o guardados previamente como texto en
descripciones, comentarios y respuestas de tareas. Las URLs sin protocolo
usan HTTPS. Se conservan los enlaces con texto personalizado, las menciones
y el código. Los enlaces se abren en otra pestaña y se validan al mostrar y
guardar el contenido.

Desde el listado de Dashboards, el creador y los administradores pueden eliminar
definitivamente paneles activos o archivados previa confirmación. Se retiran las
vistas asociadas y la configuración del panel, y se registra la eliminación.
Las tareas y listas fuente se conservan.
