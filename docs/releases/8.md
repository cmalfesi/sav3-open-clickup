# Release 8

Base: Sites release 7, source commit 7be2c1b5b5a947dc6e21aa0229124ce49679c6d8. Application package 0.8.0. Previous saved Sites versions remain available.

- Individual MCP access with task/list ACL, read-only roles and revocable personal connections.
- Extended task editing through MCP, including dates, assignees and explicit mentions.
- Description and metadata history attributed to the acting user and channel; conflict checks preserve newer descriptions.
- Shared comments and mention notifications across web and MCP.
- Inbox filters, unread counts and personal preferences.
- Durable changes notice at bottom right: five seconds, explicit refresh, persistent pending indicator and draft protection.

Validation: TypeScript, D1 service and access integration suites, UI checks and production build. See the release handoff for the exact executed outcomes and any remaining client-specific checks. External LLM clients still require compatible HTTP MCP and Bearer-header configuration; Sites' own plugin uses platform identity.
