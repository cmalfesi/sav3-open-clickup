# Release 12 · 0.9.3

KPI cards can now use heights 1, 2 and 3 instead of the previous minimum of 4 grid units. Charts, task tables and activity cards keep a four-unit minimum. Existing saved layouts retain their size. The KPI value has a saved 16–128px font-size setting, defaulting to the previous 36px. It adapts downward to the available width/height; small cards retain the full result and task count in their accessible label and tooltip. The one-unit layout uses an overlaid action cluster and compact title/value spacing.

Validation covers schema bounds, defaults for old cards, chart size constraints, and D1 persistence of the micro layout and font size. Synthetic local UI QA verifies the compact card and chosen font sizes. No original ClickUp dashboard was copied in this release: its per-card definitions are unavailable through the current connector and browser access requires completing sign-in.
